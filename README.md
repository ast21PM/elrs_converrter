# ELRX Command Builder

Веб-конвертер для сборки UART-посылок кастомного форка ELRS (**ELRX**).
Считает две команды прямо в браузере, офлайн, без бэкенда.

**Живой сайт:** https://ast21PM.github.io/elrs_converrter/

## Что умеет

| Команда | Что делает |
|---|---|
| `SET_FREQ` (cmd `0x07`) | Начало/конец диапазона (МГц) + число каналов → готовая посылка |
| `SET_UID` (cmd `0x06`) | Bind phrase (как на веб-морде ELRS) → UID через MD5 → посылка |

## Формат кадра

Любой кадр начинается с преамбулы `AB CD`, дальше байт команды и payload.

- **Частота** — три `uint32` little-endian, **в герцах**: `startFreq`, `endFreq`, `channelsCount`.
  Пример 510–540 МГц, 40 каналов: `AB CD 07 80 FB 65 1E 00 BF 2F 20 28 00 00 00`
- **UID** — первые 6 байт от `md5(-DMY_BINDING_PHRASE="<фраза>")`. Команда шлёт только последние 4 байта (`UID[2..5]`), из них считаются FHSS-seed и CRC.
  Пример фразы `TEST12` → UID `183.105.70.119.207.243` → посылка `AB CD 06 46 77 CF F3`

Приёмник опознаёт кадр только по преамбуле — длины/разделителя в кадре нет, поэтому команды шлём по одной за раз.

## Локально

Просто открыть `index.html` в любом браузере — всё считается на клиенте.
